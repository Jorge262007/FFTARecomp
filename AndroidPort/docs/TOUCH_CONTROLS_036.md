# Android 0.36: persistent touch controls

Normal touch controls remain available while the name keyboard or save selector is open. The temporary Back and Finish overlay is removed; use the existing B and Start controls. The overlay still respects the saved touch visibility, physical gamepad detection, pause state and touch editor. Removed the redundant selector polling coroutine.

Version: 36 / 0.36-touch-controls. Device gameplay verification is pending.
